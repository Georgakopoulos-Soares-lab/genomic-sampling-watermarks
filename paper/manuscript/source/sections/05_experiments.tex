\section{Experimental Design}

The primary evaluation uses Carbon-500M and GENERator-v2 1.2B on a single Apple M5 Pro system with 48~GB unified memory. Carbon-3B is an optional reduced confirmation. We first measure real next-token entropy, effective support, keyed partition balance, and information per base. Detection experiments then use paired prompts and edit seeds, globally calibrated nulls, and confidence intervals over independent sequences and keys.
