\section{Methods}

\subsection{Partition maximal coupling}

Let a keyed, equal-cardinality partition divide the $4{,}096$ canonical 6-mers into groups zero and
one, and let $q_t$ be the group-one mass under $P_t$. For a fair keyed latent bit $C_t$, maximal
coupling selects a group $G_t$ with
\[
\Pr(G_t=1\mid C_t=1)=\min(1,2q_t),\qquad
\Pr(G_t=1\mid C_t=0)=\max(0,2q_t-1).
\]
The emitted token is then drawn from $P_t$ conditioned on $G_t$. Averaging over $C_t$ recovers $P_t$
exactly at every step, so the construction is per-step distribution preserving as an identity and not
merely in expectation over a corpus. The coupling agrees, $G_t = C_t$, with probability
$1-|q_t-\tfrac12|$, and the group channel carries
\[
I(C_t;G_t)=h_2(q_t)-\tfrac{1}{2}h_2(|2q_t-1|)
\]
bits per 6-mer. This is at most one bit, which is the ceiling that governs the measured capacity: no
model entropy can widen it, because only one bit is coupled.

Both the partition and the latent bit are derived by keyed HMAC over a domain label and the stream
position, so they depend on the key, the domain, and the position, and never on the observed DNA. That
independence is what makes the verifier model-free, and Section~\ref{sec:results} shows it is also
what makes the construction spoofable under key reuse.

\subsection{Matched alternatives}

Two published exact-marginal constructions are implemented here so that the comparison happens on one
corpus rather than across papers. Neither is claimed as novel.

\emph{Inverse transform} orders the support by a keyed permutation and uses one keyed uniform to select
a point on the resulting cumulative distribution; the verifier scores how close the emitted token's
normalized rank is to that uniform. \emph{Exponential}, or Gumbel, sampling attaches one keyed uniform
$u_v$ to each candidate and emits $\arg\max_v u_v^{1/p_v}$; the verifier scores $-\log(1-u)$ at the
observed token, which is a unit exponential under the null. Both preserve $P_t$ exactly, by the
inverse-transform and Gumbel identities respectively, and both are scored without a model.

One invariant is worth stating because it shows why marginal preservation alone is insufficient
evidence: walking the cumulative distribution in the \emph{declared} order rather than the keyed order
leaves the marginal exactly correct and removes the watermark entirely. No
distribution-preservation test can detect that; only a detector can.

\subsection{The standalone detector and its declared search}

The verifier holds DNA, a runtime key, and public configuration --- no model, prompt, logits,
generation seed, or reference sequence. For one aligned hypothesis over $n$ observed tokens with $m$
keyed-group agreements the statistic is
\[
z = \frac{2m-n}{\sqrt{n}},
\]
asymptotically standard normal under the null that each token's keyed group is an independent fair
coin. The baseline detectors use the same standardization against their own known null moments, so all
three statistics are expressed in units of their own null and no method gains an advantage from scale.

The declared search enumerates both strand orientations, all six fixed-block phases, and eight
key-stream offsets, and the detector reports the \emph{maximum} statistic over it. Because the report
is a maximum over a search, its nominal normal tail is not a $p$-value; every threshold and $p$-value
in this paper is empirical, obtained by repeating the identical search on null trials. A keyed
partition depends only on the key, domain, and position, so it is cached per position and reused across
every hypothesis and every sequence, which is what makes the full search affordable.

The decision rule is strictly $z > \tau$. Because $z$ lives on a discrete lattice and $\tau$ is itself a
null order statistic, ties at the threshold are common, and a non-strict rule applied to a threshold
chosen by a strict criterion would report a smaller false-positive rate than it achieves.

\subsection{Resynchronization}

For insertions and deletions the detector may additionally declare a sliding-window search. After $D$
net inserted or deleted bases, an observed token at read index $i$ corresponds to original token
$i + (\text{phase}+D)/6$, so a window needs its own start index plus a small signed \emph{drift} rather
than an arbitrary absolute key position. Drift must be signed: deletions move content left and require
positive drift, insertions move it right and require negative drift, and a non-negative drift range
cannot reach any post-insertion segment at all. Each window length uses a stride of half its own
length, and including the full token count makes the windowed search a superset of the unwindowed one.

\subsection{Attacks under key reuse}

The attacker sees generated DNA and public configuration only: no model, no probabilities, no key, and
no detector queries. Two attacks follow directly from the statistic being a sum of per-position,
content-blind indicators. \emph{Positional splicing} builds a novel sequence by copying each token
position from one of several observed outputs, so every position inherits the group membership that
position requires. \emph{Positional shuffling} permutes token positions, so each token lands at a
position whose keyed split is unrelated to it; a bounded variant shuffles only within blocks of a given
width, which preserves more local structure. Both shuffles preserve the 6-mer multiset exactly, which
is asserted as a test invariant so that a measured removal can never be a composition change in
disguise.

\subsection{Statistical procedure}

Detection-rate intervals are joint resamples. A detection rate is measured against a threshold
\emph{estimated} from nulls, so each replicate resamples the pooled nulls, recalibrates the threshold
from that resample, and independently resamples the prompt clusters, with a cluster contributing the
mean of its own trials. Resampling only the clusters would treat an estimated threshold as known and
can report a degenerate interval on a unanimous cell. The nulls are sorted before resampling so that a
bound is a function of the null multiset rather than of the order two null families happened to be
concatenated in.

Goodness-of-fit for one-step marginal preservation uses a parametric Monte Carlo test on the $G$
statistic, because the asymptotic $\chi^2$ reference is invalid over $4{,}096$ sparsely occupied
categories. Paired proxy comparisons use exact sign-flip enumeration. Forced-choice distinguisher
accuracies are tested against a permute-and-refit null, because the decisions share a fitted direction
and relabelling against a fixed fit is anti-conservative.
